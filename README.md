# IM Workspace

Official desktop installer downloads and release notes.

## Downloads

Visit [Releases](https://github.com/im-workspace/im-workspace/releases) for available versions and platform-specific installers.

## About This Repository

This repository distributes application installers and automatic update metadata. Application source code is not published here.

Installer files are attached to releases rather than committed to the repository. GitHub's automatically generated source archives contain this download repository's files only.

## Support

Report problems through [Issues](https://github.com/im-workspace/im-workspace/issues). Include the application version, operating system, and steps to reproduce the problem. Remove passwords, access tokens, and private messages from reports and screenshots.
